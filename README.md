# Calculator
HTML • CSS • JavaScript — Interactive Arithmetic Calculator  
Live Demo: https://lavinia-81.github.io/Calculator/

A simple, responsive calculator built using vanilla JavaScript, HTML, and CSS.
This project represents one of my earliest steps into programming, where I learned how to manipulate the DOM, handle user interactions, and implement basic arithmetic logic.

---

## Overview
The Calculator application provides a clean interface for performing basic arithmetic operations.
It demonstrates foundational front‑end development concepts such as:
- event listeners
- dynamic UI updates
- input validation
- responsive design
- JavaScript logic for calculations

Even though it is a beginner project, it remains an important milestone in my learning journey.

---

## Features
### Supported Operations
- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Decimal input (.)
- Clear all (AC)
- Delete last input (DEL)
- Equals (=) to compute results

### UI & Design
- Clean and responsive layout
- CSS‑based styling
- Button grid for intuitive interaction

### JavaScript Logic
- Event handling for button clicks
- Input parsing and validation
- Real‑time display updates
- Arithmetic evaluation
- Error handling for invalid expressions

## How to Use
- Open index.html in your browser.
- Use the on‑screen buttons to enter numbers and operations.
- Press = to calculate the result.
- Use AC to clear everything or DEL to remove the last character.
- Perform any basic arithmetic operation directly in the interface.
